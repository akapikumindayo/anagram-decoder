# anagram-decoder
SKK辞書対応 日本語アナグラム解析機

利用はこちらから
(https://akapikumindayo.github.io/anagram-decoder/)

大容量のSKKオープンソース辞書（LサイズやJIS辞書など）を読み込み、ひらがなから意味のある単語や漢字表記、さらには複数単語の組み合わせ（アナグラム）を高速に検索・解析できるWebアプリケーションです。
このツールは、開発者と Gemini（GoogleのAIアシスタント） が共同で対話を重ねながら作り上げました。

🌟 主な機能
SKK辞書ダイレクト読込 & 複数辞書対応:
SKK-JISYO.L などの辞書ファイルを自動検出、または手動で複数選択して結合（マージ）できます。
動詞・形容詞の活用形自動展開:
動詞の送り仮名（例: あるk）を検出し、「か・き・く・け・こ」などの5段活用を自動展開して検索対象にします。
自然・不自然の判定と優先表示:
よく使われる自然な活用形を優先し、不自然な組み合わせには警告マーク（⚠️）をつけて視覚的に区別します。

完全一致モードのサポート:
アナグラムだけでなく、入力した言葉そのものの完全一致結果も緑色のバッジ付きで分かりやすく表示します。
漢字候補の自動表示:
検出されたひらがなに対応する漢字候補をタグ形式で一覧表示します。

🚀 使い方
ファイルの準備
このリポジトリの index.html と、お好みのSKK辞書ファイル（例: SKK-JISYO.L や SKK-JISYO.L.unannotated など）を同じフォルダ（またはディレクトリ）に配置します。
起動する
index.html をダブルクリックして、お使いのWebブラウザ（Google ChromeやEdgeなど）で開きます。
検索する
画面上のステータスが「辞書の自動読み込み完了」になったら、入力欄にひらがな（例: さくら や くるあ など）を入力し、「解析する」ボタンを押します。
モードを「一単語モード」または「二単語以上（組み合わせ）モード」に切り替えて楽しむことができます。

📁 フォルダ構成
├── index.html        # アプリケーション本体
└── SKK-JISYO.L.unannotated    -|  
└──SKK-JISYO.JIS2               |# SKK辞書ファイル
└──SKK-JISYO.JIS3_4            -|


💡 開発について
本アプリのロジック、UIデザイン、およびSKK辞書のEUC-JP/UTF-8マルチデコードや動詞の自動活用展開などの高度なアルゴリズムは、プログラミングを学ぶ開発者とAIアシスタント（Gemini）のペアプログラミング（共同開発）によって実装されました。
